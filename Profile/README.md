### 📦 Open Source per la Community Italiana

Open-sourciamo i tool che usiamo ogni giorno per le PMI. Usali, forkali, contribuisci.

#### In evidenza

- **[pmi-erp-starter-kit](https://github.com/hgsolutions-it/pmi-erp-starter-kit)** — Boilerplate ERP multi-tenant per PMI italiane. Next.js 14, Prisma, Fatturazione Elettronica. `TypeScript` ⭐
- **[gdpr-compliance-toolkit-italy](https://github.com/hgsolutions-it/gdpr-compliance-toolkit-italy)** — Checklist, template registro trattamenti, script audit GDPR in italiano. Per consulenti e aziende.
- **[cloud-migration-checklist](https://github.com/hgsolutions-it/cloud-migration-checklist)** — Checklist + script Terraform per migrare da server locali/Aruba a cloud.
- **[ai-agent-per-pmi](https://github.com/hgsolutions-it/ai-agent-per-pmi)** — Framework per agenti AI che leggono gestionali, Excel e email.
- **[fattura-elettronica-sdk](https://github.com/hgsolutions-it/fattura-elettronica-sdk)** — SDK Node/PHP/Python per creare e validare fatture elettroniche XML.
